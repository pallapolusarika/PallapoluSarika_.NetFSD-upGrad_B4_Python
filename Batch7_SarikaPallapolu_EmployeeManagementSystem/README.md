# Employee Management System

## Project Overview
This is a mini project built using HTML, CSS, JavaScript, and Bootstrap.  
It allows an admin to manage employees with features like signup/login, dashboard, and CRUD operations.

## Features
- Signup and Login with validation
- Dashboard summary (Total Employees, Active/Inactive, Department breakdown)
- Employee CRUD (Add, Edit, Delete, View)
- Filters (Search, Department, Status) with AND logic
- Sorting (Name, Salary, Join Date)
- Recent employees panel with badges
- Toast notifications for success/error messages

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap

## How to Run
1. Download and unzip the project folder.
2. Open `index.html` in any modern browser (Chrome, Edge, Firefox).
3. Use the signup form to create a user, then login.
4. Explore the dashboard and employee management features.
